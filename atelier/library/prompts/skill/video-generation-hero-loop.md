# Hero Loop

Turn a still hero visual into a slow ambient loop that plays behind the headline. The target is a background that breathes, not a video that performs. If a viewer notices the motion before they read the headline, the clip has failed.

Generate this clip **image-to-video**, always from a source frame — the clip inherits its composition, palette, and quality wholesale. Text-to-video exists on Seedance, but a hero loop has to match a hero section that already has a design, and only a source frame guarantees that. A weak still produces a weak loop; fix the still first.

## When to use

- A hero section already has a still visual and needs to feel alive.
- A CTA band, feature section, or full-bleed background needs ambient motion.
- The user asks for a "video background", "animated hero", or "moving gradient".

Do not use for: motion over the product's interface (use `Video Generation / UI Fly-Through`), an animated logo (use `Video Generation / Logo Sting`), or anything where the motion carries information rather than atmosphere. UI motion that responds to the user belongs in CSS, not in a video file.

## Get the source frame right first

- Prefer a frame generated by `Image Generation / Hero Visual`, which already reserves a quiet region and holds a contrast budget. Anything else needs the same properties before you animate it.
- The source must be high resolution and clean. Every artifact in the still gets amplified once it moves.
- One reference image on Seedance Fast and Hailuo. Seedance Pro also accepts an end frame — see loop discipline for why that matters here.
- Confirm the quiet region before generating. Motion inside the region where the headline sits is worse than a busy still, because the eye tracks movement involuntarily.

## Motion budget

The motion prompt is capped at **500 characters** and describes motion only — the frame already exists. Spend the budget in this order:

1. **Subject motion** — what the main form does. For an abstract field: drift, undulate, breathe.
2. **Background motion** — what the field behind it does, usually slower than the subject.
3. **Camera motion** — usually none. A push or pan changes framing over time, which cannot loop and will crop your text zone mid-playback.

Keep every value low. `very slow`, `subtle`, `gentle`, `barely perceptible` are the working adjectives. Concrete beats evaluative: "soft indigo ribbons undulate slowly from lower right" carries more than "beautiful flowing motion".

## Loop discipline

A hero background plays on repeat, so the cut from the last frame back to the first is the defect that matters most.

**Seedance Pro can close the loop by construction.** Supply the source still as both the first and the last frame, and the clip is forced to end exactly where it began — a mathematically closed loop, and the strongest loop tool available. When the loop is the deliverable, this is worth Pro's price on its own.

**On Seedance Fast and Hailuo, the model cannot close the loop for you.** Generation runs forward from the source frame; there is no mechanism that returns it to frame one. Asking for a "seamless loop" in the prompt reduces the size of the jump and nothing more — measured on a real 5-second Seedance clip, the last frame still differed from the first by about 6% mean pixel difference, which reads as a visible jump on repeat. On these models, plan to close the loop in the DOM (see below) and use the prompt only to make the seam small.

Everything here shrinks the seam:

- No events. No reveal, no burst, no object entering or leaving, no light turning on. An event has a before and an after, and the cut back to frame one will be visible.
- Constant speed throughout. No easing in, no settling, no slowdown at the end.
- No camera movement. A push that ends 10% tighter cannot return to its first frame.
- Keep the quiet region still. State it explicitly: motion stays in the visually active region and does not enter the area reserved for the copy.
- No lighting swing. A brightness cycle that peaks mid-clip breaks the contrast budget the still was built to hold.

## Never put the copy in the prompt

The same rule as the still: the headline, subhead, CTA label, and brand name must never appear in the motion prompt, in any form. Video models render quoted text as readily as image models do, and text that wobbles frame to frame is worse than text that is merely baked in. Close the prompt with an explicit exclusion.

## Model and resolution

| Model | Character | Credits (480p / 720p / 1080p) |
|---|---|---|
| Seedance Fast | Natural, smooth motion. The default for ambient loops. | 15 / 20 / 45 |
| Seedance Pro | Same motion family; accepts an end frame — the loop closer. | 25 / 50 / 120 |
| Hailuo | Dynamic, stylized effects. Only when the brand wants visible energy. | 30 / 30 / 50 |

Default to **Seedance Fast at 720p** for iteration, and finish on **Seedance Pro with the still as both first and last frame** when the loop must be truly seamless. 480p is for a quick look, not for a full-bleed desktop hero. Reserve 1080p for a hero that fills a large viewport and only after a cheaper pass has confirmed the motion is right — iterate cheap, finish expensive.

## Prompt skeleton

```text
Very slow ambient motion. <subject form> <drifts | undulates | breathes> gently <direction>, at a constant unchanging speed. The <background field> shifts almost imperceptibly behind it. Keep the <left 45% | quiet region> completely still and free of movement. Static camera: no push, no pull, no pan, no zoom, no rotation. No events, no reveals, no objects entering or leaving frame, no change in overall brightness. Continuous unbroken motion, ending as close to the opening frame as possible. No text, letters, numbers, logos, watermarks, subtitles, or UI elements.
```

Count the characters before sending. If it exceeds 500, cut the background clause first, then the direction — never the loop or exclusion clauses.

## Closing the loop in the DOM

When the clip carries a seam — anything not closed with Seedance Pro's end frame — hide it at playback. Two techniques, in order of preference:

**Cross-fade two offset copies.** Stack two `<video>` elements with the same source, absolutely positioned in the same box. Start the second one at half the clip duration, and cross-fade their opacity so that whichever one is approaching its end is fading out while the other is mid-clip. Neither seam is ever visible at full opacity. Costs one extra decode; acceptable for a hero.

**Ping-pong the clip.** Concatenate the clip with a reversed copy into a single file, which makes the loop mathematically seamless and doubles the duration. Northlight cannot process video files, so this is only available when the user runs it themselves — offer it, do not promise it.

Never rely on `<video loop>` alone with a raw generated clip. Watch it repeat before you decide the seam is acceptable; a slow, dark, low-contrast clip sometimes reads as a beat rather than a glitch, but that is a judgement to make with your eyes, not an assumption.

## Delivering it to the page

A generated clip is an asset, not a finished hero. When you place it:

- Mute it, autoplay it, loop it, and mark it `playsinline`. An unmuted or non-inline video will not autoplay on mobile.
- Use the source still as the `poster` frame, so the first paint matches the video exactly and there is no flash before it starts.
- Honor `prefers-reduced-motion: reduce` by falling back to the still. This is not optional politeness; motion-sensitive users get symptoms from ambient loops.
- Keep the headline in the DOM on top of the video, never inside it.

## Reject a clip when

- Any text, letterform, digit, or logo appears, or flickers in and out across frames.
- Anything moves inside the quiet region where the copy sits.
- The seam is still obvious after cross-fading: a hard jump, a settle, or a lighting mismatch between the last and first frames. Some seam is expected; an eye-catching one is not.
- The framing drifts, so the composition at the end is not the composition at the start.
- Overall brightness rises or falls during the clip, breaking the contrast the still was built for.
- The motion is fast, busy, or attention-grabbing enough to compete with the headline.
- Faces, hands, or recognizable objects emerge out of an abstract field as it moves.

Always place the clip in the real hero block, with the real headline on top and the cross-fade wired up, and watch it loop at least three times before calling it done. Loop seams are invisible on a single play.
