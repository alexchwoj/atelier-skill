# Hero Window Composition

> Builds a full-screen hero section with strong text readability, premium layout, poetic headline formatting, and complete above-the-fold structure.


---

Create a full-screen Impact Minds hero section where the first visible browser window contains the full above-the-fold experience.

The initial hero window must include:

- menu bar at the top
- breadcrumbs directly below the menu bar
- full hero image or cinematic hero animation
- headline
- subheadline
- primary CTA
- secondary CTA
- micro-reassurance line

Everything must fit within the first visible screen without pushing key content below the fold.

Prioritize text readability above all else.

If text is difficult to read on the image or animation background, automatically improve readability using:
- a soft overlay panel
- a translucent neutral text container
- a subtle gradient fade
- stronger text contrast
- an adjusted text color

Do not heavily darken or recolor the photo. Preserve the natural warmth and visual tone of the image whenever possible.

Brand typography:
- Roboto for headline and subheadline
- Garet for breadcrumbs, micro-reassurance line, UI labels, accents, and icons
- Roboto Slab only for quotes

Headline styling:
- format the headline with poetic line breaks
- let it read like a short stanza
- emphasize 1 to 2 important words only
- use italics sparingly and intentionally
- emphasis should reinforce the page meaning
- maintain premium restraint
- avoid over-stylizing

Subheadline styling:
- support the headline with elegant wrapping
- keep it calm, grounded, and highly readable
- allow it to feel like a continuation of the headline rhythm
- preserve clean spacing and clear hierarchy

Layout:
- keep hero text in a safe readable zone
- maintain strong contrast
- ensure CTA buttons are clearly visible within the first screen
- keep breadcrumbs horizontal and aligned below the menu
- use cinematic spacing and editorial balance
- hero image may use subtle parallax if available

The hero should feel:
- premium
- immersive
- calm
- structured
- editorial
- emotionally grounded

Reference style:
Apple-style product page opening
Luxury wellness editorial layout
High-trust healthcare brand hero
