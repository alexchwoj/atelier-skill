# Ratio

> margins, cards, ui elements, height.


---

Design for a 1440px–1600px canvas, not full 1920px.

Constrain all content to a centered container of 1200px–1320px max width.

Maintain strong left and right margins (80px–120px).

Do not stretch content edge-to-edge except for background images.

Keep all cards, text blocks, and UI elements within the contained grid.

Hero sections should use 80–90vh height so all key content (headline, CTA, and micro insurance line) remains visible without cropping.

The design should feel contained, structured, and premium — not wide or oversized.
