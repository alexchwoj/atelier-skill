# Copy Preservation

> Preserves original copy exactly. May add clearly labeled missing support content, but never removes, rewrites, shortens, or invents facts.


---

Preserve the original copy exactly as provided.

Non-negotiable rules:

1. Do not rewrite the user’s original copy.
2. Do not shorten, paraphrase, simplify, polish, or reword existing copy.
3. Do not remove any sentence, phrase, bullet point, CTA, disclaimer, heading, subheading, label, or section.
4. Do not exclude copy for brevity, layout convenience, or design preference.
5. Do not “improve” tone, wording, or clarity unless the user explicitly asks for copywriting changes.
6. If copy is too long for a layout, adjust the design, spacing, typography, or section structure instead of changing the copy.
7. If content is missing and the page clearly needs a support element, you may add only the missing structural content, such as:
   - FAQ questions
   - placeholder labels
   - section dividers
   - button labels already implied by the page
   - CMS field placeholders
8. Any added content must be clearly marked as added support content and must not replace original copy.
9. Never invent or generate statistics, percentages, rankings, research claims, or outcomes unless they were explicitly provided by the user.
10. Never fabricate credentials, insurance claims, accreditations, research backing, dates, locations, or performance data.
11. If a fact is missing, leave it blank, label it as a placeholder, or ask for it rather than inventing it.
12. Maintain all original headings, section order, bullets, CTAs, and key phrases unless the user explicitly requests restructuring.
13. Keep the original message, tone, and wording intact.
14. When in doubt, preserve rather than change.

Priority order:
1. Preserve original copy
2. Preserve factual accuracy
3. Preserve section hierarchy
4. Improve layout without editing text

Design behavior:
- Solve overflow with spacing, layout changes, card resizing, typography adjustments, containers, or section expansion
- Do not solve layout problems by cutting or rewriting text
- Keep CTAs exactly as written
- Keep pillar order, framework order, and branded language exactly as provided

If support content must be added, use this label:
[Added support content]

Examples:
- Allowed: adding FAQ placeholders if the user requested an FAQ section but did not provide questions
- Allowed: adding “Image placeholder” or “CMS content block” labels
- Not allowed: rewriting a paragraph to be shorter
- Not allowed: replacing original bullets with summarized bullets
- Not allowed: inventing data or claims to make the page sound stronger

Final rule:
Original copy is the source of truth. Protect it.
